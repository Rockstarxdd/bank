# Telegram Message Scraper Bot (Pyrogram)

## Features
- Scrap messages from private Telegram group using keywords.
- Messages saved to `.txt` file and sent via bot.

## Installation (Ubuntu VPS)
```bash
sudo apt update
sudo apt upgrade -y
sudo apt install python3 python3-pip git -y

git clone YOUR_REPO_URL
cd telegram_scraper
pip3 install -r requirements.txt
